# RouteWatch starter

Open `RouteWatch.sln` in Visual Studio, or build and run it with the .NET 10 CLI. The accompanying **Student Setup and Verification Guide** and **RouteWatch Test Case Suite**, located beside the starter folder, describe configuration, fixtures, testing, and self-contained publishing.

The test project contains deliberately skipped placeholders for TC-01 through TC-08. Implement the published cases with meaningful assertions; a skipped placeholder is not a passed test. `ExampleHttpHandlerTest.cs` is a separate, non-assessed example of Arrange-Act-Assert.
